src/routes/PlayerDetail.tsx renders count(row.gold ?? 0) in the arrival card. 1,750 player rows state no gold, so reaching one through ?from= prints "0 gold" — a missing measure presented as a measured zero, against the orDash doctrine the project states everywhere.

Use orDash, and check cs the same way.

## Done — fix/player-gold-dash

The card's measure line now renders through `measureWithUnit` (`src/lib/format.ts`),
which prints the figure via `orDash` and, when there is none, names the measure
instead. `row.cs` went the same way; it was printed raw, so a null would have
rendered "null CS".

A bare dash could not be used there: the unit is glued to the number inline, so
"— gold" reads as a broken figure. The absence is written out — "gold not
stated" — matching the "format not stated" a series already uses. Where the
measure exists nothing changed: "277 CS · 15,188 gold".

- `src/lib/format.ts` — new `measureWithUnit`, with the reasoning in its comment.
- `src/routes/PlayerDetail.tsx` — the arrival card's measure line, gold and CS.
- `src/lib/format.test.ts` — the present / absent / measured-zero cases.
