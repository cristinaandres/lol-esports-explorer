`match_key` 0 is the model's placeholder match: `match_name` "Unknown", every other field null. A player reached through `?from=game:gm-00a3d746cd96` gets an arrival card whose series line reads "Unknown", which reads as a series called that rather than as a game that stands alone.

Either omit the line when the game has no series, or say it plainly ("no series recorded"), following the site's rule that absence is worded rather than dashed or faked. The card's other fields already distinguish stated from unstated, so the series line is the odd one out.

Check: the arrival card for a `match_key = 0` game states the absence, and a game with a real series still names it.
