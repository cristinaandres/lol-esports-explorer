**Source:** complexity review, finding 5.

`.devcontainer/Dockerfile` runs `npx --yes playwright install-deps chromium`. That resolves whatever Playwright npm published when the image was built, so two builds of the same commit install different package sets — the image is not reproducible.

**Fix.** Pin it to the Playwright version the pinned `@playwright/mcp` depends on (currently `1.66.0-alpha-2026-11-18`, per `node_modules/playwright/package.json`), e.g. `npx --yes "playwright@1.66.0-alpha-2026-11-18" install-deps chromium`, and note beside it that it is bumped with `@playwright/mcp`.

**Trade-off to accept:** a second place to bump. The alternative — hardcoding the ~95 apt package names — is worse, and `postCreate.sh`'s screenshot smoke test is what catches a gap either way.

**Verify.** `devc rebuild` on a machine where it is wanted: the layer installs, and postCreate prints "Playwright Chromium is installed and launches." (Not verifiable from CI.)
