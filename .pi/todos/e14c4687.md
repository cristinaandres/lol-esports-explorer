Two tests passed for less than their names claimed, so a real regression would
have stayed green.

**Changed.** `src/lib/search.test.ts` no longer asserts only that `illum` matched
something. The fixture now carries Illuminar Gaming, which `illum` prefixes while
it sits inside Nunu & Willump, and the test asserts the order of the two results.
A second test finds a name by "willump", a string that prefixes nothing, so "a
mid-word match is found" stays a claim of its own rather than a side effect of the
ranking one.

`src/lib/data.test.ts` walks games.json and sides.json together and asserts
`winnerKey(game)` is the team whose side row states `is_winner`: the upstream
model's per-side column, copied by this repository, against a predicate that reads
the game-level `blue_win`. On a red win the two arrive from opposite directions,
so the witness does not restate the predicate. The test also asserts every game
has exactly one winning side, so a game with two winners or none fails instead of
quietly shrinking the comparison.

**Verified.** Mutation evidence, both reverted before the commit: swapping the
prefix and includes ranks in `src/lib/search.ts` failed the ordered search test,
printing Nunu & Willump before Illuminar Gaming; returning the losing team from
`winnerKey` produced 3,091 mismatches, one per game. That blunt mutation also
trips the restatements in `game.test.ts`, so the consistently wrong predicate was
exercised too — making those restatements agree left `game.test.ts` green and the
new artifact test as the only failure (49 passed, 1 failed across the two files).
`npm run check` green: 234 vitest tests, 10 pipeline tests,
`public/data is current (16 files)`, production build.

**Not tested.** Nothing outstanding; no behaviour outside the tests changed.
