## Done

Removed `recharts` from `dependencies` and let npm rewrite `package-lock.json`
with `npm install --package-lock-only`, then dropped the 39 orphaned packages it
leaves behind from the shared `node_modules`. No charting replacement: the
ticket's point is that the choice belongs to whoever draws the first chart.

**Unused, proved three ways.** `grep -rn recharts` finds nothing in `src/`
(exit 1), `pipeline/` or `docs/`, in this branch and in every other worktree of
the repository. The production bundle never held it: before the change the build
emitted 142 modules and `index-CQ8ljdck.js` at 384,159 bytes (111.00 kB gzip),
and that file contained zero occurrences of `recharts`, `victory-vendor` or
`d3-scale` — Vite only bundles reachable imports, so an unimported dependency
cannot be in there.

**Lock.** 188 package entries before, 149 after; the 39 removed are recharts and
its exclusive subtree (victory-vendor, d3-* and their `@types`, @reduxjs/toolkit,
react-redux, reselect, redux, redux-thunk, immer, clsx, es-toolkit,
eventemitter3, decimal.js-light, tiny-invariant, use-sync-external-store,
react-is, @standard-schema/*). No remaining entry depends on any of them, and no
entries were added.

**Measured effect.** None in shipped bytes: the rebuilt bundle is byte-identical
(same hash, 384.15 kB, 142 modules), which is exactly what an unused dependency
should cost. The gain is install size and a smaller audit surface.

Verified with `npm run check` from the branch worktree: oxlint clean apart from
the two warnings that are already on `dev` (EraGrid.tsx, ChampionDetail.tsx),
196 tests in 15 files passing, `public/data is current (16 files)`, production
build byte-identical. `npm ls recharts` now prints an empty tree.

**Also seen, not touched.** `npm install --package-lock-only` corrected the lock's
root name from `scaffoldsrc` to `lol-esports-explorer`, a rename package.json had
already taken without regenerating the lock; those two lines are in the diff and
worth a glance. The worktree's `node_modules` is a symlink to the main checkout,
so the dependency left the shared tree for every checkout, and `node_modules`
shows as untracked because `.gitignore`'s `node_modules/` pattern does not match
a symlink.
